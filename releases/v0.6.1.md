# Ask the Model v0.6.1

Released: 2026-10-08

## Summary

This compatible correction makes the qualified GISTEMP chart usable from ordinary natural-language requests and removes an unintended dependency on retrieval excerpt selection during chart construction.

## Changes

- Recognize clear Romanian and English requests for a GISTEMP/global-temperature chart in addition to the explicit `/chart gistemp` command.
- Construct the chart from the complete pinned and revalidated EWD GISTEMP source, so sparse retrieval excerpts cannot make the application claim that the series is unavailable.
- Keep intent detection, source qualification and chart values under application control.

## Boundaries

This release remains limited to the existing qualified annual global GISTEMP profile. It does not add generic charting, arbitrary data sources, model-authored chart values or chart configuration. Existing History reconstruction continues to use the pinned source recipe.
