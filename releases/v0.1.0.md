# Ask the Model v0.1.0

**Application baseline — initial public release**

Ask the Model (AtM) v0.1.0 is the first formal public snapshot of the application.

The release establishes the native application shell and desktop integration baseline. The intended product role is a local AI conversational access layer for scientific model repositories, but repository-aware AI chat functionality is not implemented in this release.

## Included

- GTK 4 and Granite 7 application shell;
- stable application ID `io.github.laurentiustaicu.ask_the_model`;
- Meson build and installation configuration;
- freedesktop desktop launcher metadata;
- AppStream application metadata;
- elementary-compatible application icon sizes;
- standardized AtM project identity and MIT licensing.

## Application status

AI chat functionality, repository access, local model-provider integration, conversation management and settings are not implemented in v0.1.0.

AtM does not contain or replace the scientific models. Each model remains canonical in its own repository.

## Versioning

The project follows Semantic Versioning. The `0.x.y` series denotes initial development.
