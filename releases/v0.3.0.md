# Ask the Model v0.3.0

**Repository-Grounded Multi-Chat — 2026-09-20**

Ask the Model v0.3.0 is the first public release of the repository-aware conversation path for the fixed Empirical World3 Dynamics (EWD), Cognitive Belief Dynamics (CBD) and Romanian Monetary Dynamics (RMD) suite.

It preserves ordinary local AI chat while adding validated local repository snapshots, deterministic retrieval, per-conversation repository/model pinning, multi-chat navigation and exact source provenance.

## Included

- a fixed EWD/CBD/RMD repository selector with independent multi-selection;
- explicit repository Refresh and Download/Update lifecycle controls;
- SHA-pinned validated immutable local source snapshots under `~/Ask the Model/Repositories`;
- bounded safe archive extraction, strict manifest/CITATION validation and deterministic per-snapshot indexes;
- deterministic exact-ID, structured, lexical BM25 and tabular retrieval without requiring embeddings;
- conservative Romanian/English query normalization with protected technical identifiers;
- per-chat repository and local-AI model identity frozen at the first Send;
- real independent chat tabs with a compact New control, automatic semantic titles of at most three words and per-tab close controls;
- separate in-memory Ollama conversation history and repository-grounding state for every chat tab;
- transactional grounded turns so failed generation or invalid provenance does not advance retrieval-conversation state;
- current-turn repository evidence that is not persisted as ordinary chat-history grounding blocks;
- fail-closed temporary `[S#]` source-label validation before grounded turns are committed;
- compact `Sources: [1] [2]…` references below grounded answers;
- on-demand provenance containing repository/version, exact snapshot SHA, logical source ID, physical source locator, evidence excerpt and immutable GitHub permalink when available;
- an embedded status LCD for AI/repository lifecycle state;
- ordinary zero-repository local chat retained as a separate streaming path;
- the validated frozen R5 retrieval benchmark and real-repository R4 traceability gates.

## Conversation and repository boundary

A repository selection and AI-model selection are editable before the first user message in a chat. The first Send pins those identities for that conversation. A new scope or AI model belongs in a new chat rather than silently changing the scientific basis of an existing conversation.

Each scientific model remains authoritative in its own repository. AtM retrieves and presents repository evidence but does not redefine repository content or convert AI-generated interpretation into a canonical scientific-model result.

## What remains outside v0.3.0

- persistent conversations across application restarts;
- arbitrary repository support beyond the fixed EWD/CBD/RMD catalog;
- provider host/port, authentication or TLS settings in the UI;
- provider installation/start/stop/update management;
- AI-model download/import/update/delete inside AtM;
- cloud AI providers;
- execution or simulation of EWD, CBD or RMD;
- autonomous modification of scientific repositories.

## Validation

The repository-grounded stack reached `main` only after the combined branch passed the Flatpak/Meson/Vala suite, real-repository R4 citation traceability and the frozen R5 retrieval benchmark. The R5 gate is an engineering acceptance result for the pinned retrieval corpus, not a scientific-validity claim about EWD, CBD or RMD.
