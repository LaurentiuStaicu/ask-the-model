# Ask the Model v0.1.1

**Application scope and documentation correction**

Ask the Model (AtM) v0.1.1 formalizes the application's role as a local AI conversational access layer for repositories of scientific dynamical models.

The initial dynamical-model repository suite includes Empirical World3 Dynamics (EWD), Cognitive Belief Dynamics (CBD) and Romanian Monetary Dynamics (RMD).

## Included

- corrected and expanded project README;
- canonical application boundary in `STATUS.md`;
- citation metadata in `CITATION.cff`;
- corrected desktop and AppStream descriptions;
- standardized repository icon and release documentation;
- explicit separation between the AtM interface and the scientific models.

## Application status

This release does not introduce AI chat functionality.

AtM is the conversational interface. EWD, CBD and RMD remain independent, canonical scientific-model repositories.

See `STATUS.md` for the maintained application boundary and `CITATION.cff` for citation metadata.

## Versioning

The project follows Semantic Versioning. The `0.x.y` series denotes initial development.
