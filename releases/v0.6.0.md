# Ask the Model v0.6.0

**Qualified Presentation, Repository Optimizations and GISTEMP Charts — 2026-10-08**

Ask the Model v0.6.0 retains the exact-SHA repository grounding, saved-conversation History and hardened state boundaries of v0.5.0. It adds qualified semantic presentation, an explicit source-revalidated GISTEMP chart path and a session-only repository optimization mode that defaults to OFF.

## Semantic transcript presentation

- Complete assistant responses receive restrained semantic presentation for headings, lists, quotes and code.
- Grounded Sources remain separate, focusable buttons with accessible names and validated first-use numbering.
- Copying selected transcript text serializes source anchors as visible `[N]` references and omits spinner and separator widgets.
- Live and History turns use a shared completed-turn presentation path without rewriting stored conversation content, provider history or citation provenance.

## Explicit GISTEMP chart path

A user may request a chart with `/chart gistemp <grounded question>`. AtM accepts only the qualified complete annual global GISTEMP series from the pinned EWD snapshot, revalidates the source before rendering, and persists a reconstruction recipe rather than numeric points or pixel state. History rebuilds the chart from the exact pinned source and fails closed when the snapshot or recipe cannot be qualified.

Generic chart intent, model-authored numeric data or configuration, arbitrary scientific sources, STEP/BAR and missing/event series remain unsupported.

## Session-only Optimizations

The global **Optimizations** control starts OFF in each process and is not persisted. OFF retains the established baseline. ON enables individually qualified paths, including repository mutation coordination, shared generation leases, retrieval-index single-flight, conservative local-capacity admission, D1 source-cap-4 context and selected S1 local-filesystem durability.

C1 reclamation is bounded to the qualified post-action path. It is not triggered at startup, in the background, by toggle changes, or by ENOSPC. No general cache eviction, Control DB generation pruning, quarantine purge or conversation-delete cascade is added.

## Grounded turn integrity

Grounded provider turns bind the session's model and repository generation identity at start and re-read current identity before commit. Identity drift fails closed with `STALE_IDENTITY`; cancellation before commit prevents persistence and provider-history advancement.

## Qualification and scientific boundary

The release candidate is qualified by the CHART-01/03, PRES-09, Presentation Interaction, D1, C1-I9/I10/M1, A1-M12/M12b, Invariant Registry and Flatpak gates. Qualification covers software behavior and evidence handling; it does not certify the scientific validity of EWD, CBD, RMD, GISTEMP or AI-generated interpretation. The final release metadata commit must pass the complete CI set before merge or tagging.
