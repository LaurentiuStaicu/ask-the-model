# Ask the Model v0.2.2

**Documentation and public-metadata consistency — 2026-09-20**

Ask the Model v0.2.2 is a patch release that preserves the existing Local Chat Baseline while making the public presentation, first-time setup guidance and packaged application metadata consistent with what the application actually implements today.

## Included

- a substantially reorganized README designed for first-time local-AI users;
- a compact, consistent repository header with linked release, license and platform metadata;
- smaller explanatory body text and progressive disclosure for secondary technical sections;
- a complete first-time setup path with expected results after each major step;
- explicit documentation that AI models must currently be downloaded and managed through the provider rather than AtM;
- explicit documentation of AtM's automatic provider-based model discovery and Refresh behavior;
- practical guidance for finding models through Ollama Library and Hugging Face;
- explanations of GGUF, quantization, model size, context, model licenses and CPU/GPU placement;
- practical model-management commands for download, listing, memory unloading and deletion;
- a new `docs/MODEL_GUIDE.md`;
- a new `docs/TROUBLESHOOTING.md`;
- corrected privacy wording that distinguishes AtM's loopback connection from capabilities of the external provider;
- corrected `CITATION.cff`, AppStream and desktop-launcher metadata.

## Application status

The application behavior is unchanged from v0.2.1.

AtM can:

- discover a supported local Ollama-compatible provider;
- enumerate provider-managed models;
- filter the model list to completion-capable models;
- refresh model discovery without restarting;
- select a compatible AI model;
- stream text-chat responses;
- maintain multi-turn conversation context in memory for the current application session.

## Important model-management boundary

AtM v0.2.2 does not download, import, move, update or delete AI models itself.

Those operations remain the responsibility of the external provider. With Ollama, users can manage models with commands such as:

`ollama pull MODEL`

`ollama ls`

`ollama ps`

`ollama stop MODEL`

`ollama rm MODEL`

After provider-side model changes, AtM's **Refresh models** action repeats discovery and updates the selector.

## Scientific-repository boundary

Natural-language exploration of EWD, CBD, RMD and other scientific dynamical-model repositories remains a project direction rather than an implemented v0.2.2 feature.

Repository-aware retrieval, provenance tracing and scientific-model execution are not yet implemented. Scientific repositories remain external and authoritative.

## Versioning and release integrity

v0.2.1 remains frozen as originally released.

The documentation and packaged metadata changes made afterward are published as v0.2.2 rather than being attached retrospectively to the v0.2.1 release. This keeps a version tag and its distributed Flatpak artifact tied to one release state.
