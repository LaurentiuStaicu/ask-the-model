# Ask the Model v0.6.2

Released: 2026-10-08

## Summary

This compatible correction hardens the durable commit boundary for repository-grounded conversation turns.

## Changes

- Advance grounded `ConversationSession` state only after the corresponding durable SQLite turn commits successfully.
- Require final cancellation, model-identity and repository-generation checks immediately before the synchronous durable commit.
- Fail closed when pre-boundary durable persistence cannot be established, including durable conversation identity creation and citation persistence failures.
- Keep provider history deferred until the durable boundary succeeds.
- Preserve committed durable turns when later chart, presentation or title work fails instead of aborting already-persisted grounding state.
- Add the `SESSION-S0-013` invariant plus structural and semantic regression qualification for ordering, persistence failure and retry behavior.

## Boundaries

This is a compatible reliability correction. It does not add new user-facing scientific capabilities, change repository authority, alter the v0.6.1 GISTEMP chart scope, or change the default-OFF optimization policy.

The v0.6.1 tag and immutable release remain unchanged as the historical previous release.
