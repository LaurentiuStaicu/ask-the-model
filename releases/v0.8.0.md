# Ask the Model v0.8.0

Release date: 2026-10-15

**Bounded BNR BLS C01 quarterly chart route — 2026-10-15**

## Summary

v0.8.0 adds one source-qualified BNR BLS C01 quarterly chart route alongside the established GISTEMP v1 and Energy Institute TES v2 profiles. The existing GISTEMP and Energy Institute contracts remain unchanged.

## Changes

- Add the `/chart bnr-bls-c01` path and narrowly qualified natural-language routing for explicit C01-specific intent.
- Read BNR data only from the exact pinned RMD snapshot `e43eb4e899f123d3b1aa0f6e20b7c8ed35434170`.
- Preserve all 12 quarter coordinates, 11 numeric observations and the authority-qualified missing coordinate at 2025-Q2 with reason `source_round_not_retained`. No physical CSV row or numeric zero is fabricated; the Data view displays `none` and the renderer does not bridge the missing quarter.
- Keep History recipe-only: reopening reconstructs chart/Data presentation from the pinned source and fails closed if source identity or qualification changes.
- Clarify that B0 repository-authority mutation coordination and B2 positive-generation shared leases are mandatory in Optimizations OFF and ON modes. Optional qualified optimization paths remain behind the session-only, default-OFF switch.

## Scope and qualification boundaries

- GISTEMP v1 and Energy Institute TES v2 behavior remains unchanged.
- This release does not add generic chart discovery, arbitrary sources, multi-series/derived charts, generalized missing/event/discontinuity semantics, upstream Energy Institute raw-to-processed reproduction or M4 activation.
- Broader CHART-01 qualification remains open in issue #343. The fixed EWD/CBD/RMD repository catalog and scientific-source provenance boundaries remain in place.

## Publication gate

The release workflow publishes from the metadata-bearing `main` commit. Before that merge, the exact generated `AskTheModel.flatpak` artifact must pass the on-device acceptance checklist in issue #481 on elementary OS 8. The final direct `v0.8.0` tag and published asset digest must be checked against the accepted artifact; PR CI alone is not a substitute for this acceptance.
